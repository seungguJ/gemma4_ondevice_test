### 작업명

Wallet 알림에서 `결제 완료` 문구가 있는 금액만 월 누적 반영

### 목적

포인트 적립/혜택성 알림에도 금액이 포함되어 잘못 누적되는 문제를 막기 위해,
Samsung Wallet 알림 중 `결제 완료` 문구가 있는 건만 거래로 저장되도록 조건을 강화한다.

### 변경 대상 파일

- `app/src/main/java/com/example/gemma4ondevicetest/wallet/WalletNotificationParser.kt`
- `app/src/main/java/com/example/gemma4ondevicetest/wallet/WalletParserRules.kt`
- 필요 시 관련 Wallet 모듈 문서 최소 범위 갱신

### 구현 요구사항

- 거래 저장 조건에 `결제 완료` 문구 존재를 추가한다.
- `포인트`, `혜택` 등 금액이 있더라도 `결제 완료`가 없으면 저장되지 않아야 한다.
- 기존 승인 취소 처리와 월 누적 구조는 유지한다.
- 조건 실패 시 파싱 실패 사유가 너무 모호하지 않게 남도록 한다.
- 변경 범위는 Wallet 파싱 규칙에 한정한다.

### 금지 사항

- 일정 기능이나 다른 화면 로직 수정 금지
- 저장소 구조 변경 금지
- 임시 하드코딩 샘플 데이터 추가 금지
- 광범위한 리팩터링 금지

### 검증 방법

- 관련 Kotlin 코드 정적 검토
- 가능하면 프로젝트 빌드 또는 최소 컴파일 검증
- 빌드가 불가능하면 그 사유를 명시

### 완료 조건

- `결제 완료`가 없는 Wallet 금액 알림은 누적되지 않는다.
- `결제 완료`가 있는 결제 알림은 기존처럼 월 누적된다.
- 수정 파일과 검증 결과, 남은 리스크가 보고된다.
