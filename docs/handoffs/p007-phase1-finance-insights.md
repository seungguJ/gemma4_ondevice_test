### 작업명

금융 인사이트 1차 구현: 후보 통합, AI 카테고리 분석, 시각화 데이터

### 목적

카드 사용내역 기능을 단순 월 합계/최근 거래 화면에서 확장해, 정기결제 후보와 동일한 규칙 기반 후보 집합을 기준으로 AI 카테고리 분석과 시각화 가능한 금융 인사이트를 제공한다.

### 구현 요구사항

- 현재 카드 사용내역 분석의 입력 집합을 단순 Samsung Wallet 저장 거래 전체가 아니라 `정기결제 후보와 동일한 1차 규칙 기반 후보 집합`으로 맞춘다.
- 여기서 말하는 동일 기준은 최소한 `SubscriptionAnalysisRules.evaluate(...)`와 동일한 패키지/키워드 게이트를 공유하거나, 두 기능이 같은 평가 결과를 재사용하도록 만드는 것이다.
- 기존 카드 거래 저장 자체는 유지하되, 분석 대상 후보와 월 누적 원본 거래는 구분 가능해야 한다.
- 1차 규칙 기반 후보를 따로 저장하거나 재구성할 수 있어야 하며, 화면에서 그 수와 상태를 보여줄 수 있어야 한다.
- AI 분석은 기존 정기결제 분석과 마찬가지로 배치형으로 수행한다.
- AI 분석은 후보 거래들을 카테고리별로 분류하고, 카테고리별 합계/건수/대표 설명을 만들 수 있어야 한다.
- 카테고리는 과도하게 세분화하지 말고 실제 사용자 이해가 쉬운 수준으로 제한한다. 예: `식비`, `교통`, `쇼핑`, `구독`, `생활`, `의료`, `금융`, `기타`.
- AI 출력은 자유 텍스트가 아니라 구조화된 JSON으로 파싱 가능해야 한다.
- 분석 결과 저장 모델에는 최소한 아래 정보가 들어가야 한다.
- `generatedAt`
- `lastCompletedAt`
- `pendingCount`
- `analyzedCandidateCount`
- `statusMessage`
- `overallSummary`
- `category breakdown list`
- `top merchants or representative services`
- 카드 사용내역 화면에 아래 요소를 추가한다.
- AI 분석 상태 카드
- 카테고리별 요약 카드 또는 리스트
- 시각화용 데이터 기반 UI
- 시각화는 Compose만으로 표현 가능한 수준이면 충분하며, 최소한 비율 막대/세그먼트 바/상위 카테고리 비교 등 사용자가 한눈에 볼 수 있는 형태여야 한다.
- 시각화 데이터는 단순 문자열이 아니라 실제 수치 모델을 기반으로 그리도록 구현한다.
- 홈 화면에서 카드 사용내역 진입 카드가 `월 합계만` 보여주지 말고, 대표 카테고리 또는 분석 상태를 한 줄로 보여주도록 개선한다.
- 정기결제 후보 화면이 이미 있다면, 카드 인사이트와 역할이 겹치지 않도록 구분한다.
- AI 분석 시 모델 상주 금지 원칙을 지킨다.
- 분석 시작 시에만 모델을 로드하고, 종료 후 `LlmEngine.clearSession()`과 `LlmEngine.free()`가 보장되어야 한다.
- 다른 화면이 모델을 사용 중일 때는 안전하게 보류 또는 재시도하도록 한다.
- 기존 Wallet 월 합계/최근 거래/로그 화면은 깨지지 않아야 한다.
- 기존 정기결제 후보 기능을 제거하지 말고, 카드 인사이트 분석이 그 후보 기준을 재사용하는 방향으로 확장한다.

### 금지 사항

- 기존 카드 거래 저장 로직을 삭제하거나 월 누적 기능을 깨뜨리지 말 것
- AI를 알림 수신 시점마다 즉시 호출하지 말 것
- 분석 결과를 파싱 불가능한 자유 형식 문자열만으로 저장하지 말 것
- 외부 차트 라이브러리 추가 금지
- 사용자 기존 변경을 덮어쓰지 말 것
- 광범위한 구조 개편으로 범위를 불필요하게 키우지 말 것

### 검증 방법

- 후보 평가 규칙이 정기결제 후보와 동일 기준을 쓰는지 코드 경로 확인
- AI 분석 프롬프트와 JSON 파싱 경로 정적 검토
- 분석 전후 `loadModel`, `clearSession`, `free` 호출 경로 확인
- 카드 사용내역 화면에서 월 합계/최근 거래/분석 요약/시각화가 함께 보이는지 확인
- 홈 카드에 대표 인사이트가 반영되는지 확인
- 가능하면 단위 테스트 또는 최소 컴파일 검증 수행
- 빌드 불가 시 그 사유를 명시

### 완료 조건

- 카드 인사이트 분석이 정기결제 후보와 동일한 규칙 기반 후보 집합을 사용한다.
- AI가 카테고리별 분석 결과를 구조화된 데이터로 저장한다.
- 카드 사용내역 화면에 카테고리 요약과 시각화가 추가된다.
- 홈 카드에 대표 금융 인사이트 또는 분석 상태가 반영된다.
- 모델 로드/언로드 정책이 유지된다.
- 수정 파일, 검증 결과, 남은 리스크를 보고한다.
