### 작업명

Claude 연결 확인

### 목적

Codex에서 `scripts/claude_handoff.sh`를 통해 Claude CLI와 실제로 대화가 가능한지 확인한다.

### 변경 대상 파일

- 없음

### 구현 요구사항

- 코드 수정 없이 짧은 한국어 응답만 반환한다.
- 응답에는 `연결 확인 완료` 문구를 포함한다.
- 응답은 보고 형식을 따른다.

### 금지 사항

- 프로젝트 파일 수정 금지
- 장황한 설명 금지

### 검증 방법

- handoff 스크립트 실행이 성공 종료될 것
- `.claude/handoffs/`에 prompt, response, meta 파일이 생성될 것
- response 파일에 `연결 확인 완료`가 포함될 것

### 완료 조건

- Claude 응답을 수신하고 저장 경로를 확인한다.

### 보고 형식

- 수정 파일
- 주요 변경 내용
- 검증 내용
- 남은 리스크
